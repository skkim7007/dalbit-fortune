# 달빛 운세

가입 없이 브라우저에서 사주와 이름 후보를 살펴보는 정적 웹 서비스입니다. [k-skill](https://github.com/NomaDamas/k-skill)의 MIT 라이선스 `saju-fortune`, `naming-house` 패키지를 사용하며 점신의 다양한 주제 선택 흐름을 참고한 독립 프로젝트입니다.

- 양력 날짜와 선택적 출생 시간으로 사주·오행·주제별 풀이를 계산합니다. 음력은 별도 변환해야 합니다.
- 이름 후보를 입력하면 사주 오행, 획수, 발음과 선호 항목의 점수를 비교합니다. 한자 필순은 강희자전 획수나 인명용 한자 검증이 아닙니다.
- 자유 입력 질문은 AI가 아닌 키워드 분류 기반으로 사주 패키지의 해당 주제 안내를 반환합니다. 세부 질문에는 답하지 못합니다.
- 입력값은 브라우저 메모리에서만 사용하며 저장하거나 서버로 전송하지 않습니다. Google Fonts는 글꼴 요청 시 방문자 IP 등이 Google에 전달될 수 있습니다.
- 결과는 재미와 자기 성찰을 위한 참고용으로 의료, 법률, 투자 등 중요 결정을 대신하지 않습니다.

## 개발

```sh
npm install
npm test
npm run build
```

`index.html`, `style.css`, 빌드된 `app.js`를 GitHub Pages의 루트에서 제공하면 됩니다.
